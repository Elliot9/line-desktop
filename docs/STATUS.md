# 功能與驗證狀態

這份清單區分程式已接上的路徑與實際服務互通驗證。離線示範成功不代表 LINE 伺服器已接受該操作。

| 功能 | 目前實作 | 驗證範圍 |
| --- | --- | --- |
| 原生介面 | GTK 4，聊天、好友、搜尋、設定、詳細資訊 | Debian 12 GTK 4.8 與 Ubuntu 24.04 GTK 4.14，ARM64 容器實際操作 |
| 登入 | QR、電子郵件、手機 PIN、取消 | 真實 LINE QR 挑戰產生及取消通過；完整帳號登入未驗證 |
| 登入保存 | 系統鑰匙圈保存 token、憑證與匯出金鑰；不可用時僅存記憶體 | 隔離 Secret Service 寫入、還原與刪除測試 |
| 好友與聊天 | 取得好友、既有私訊與群組、近期訊息、未讀狀態 | 已接上游 API；真實帳號同步未驗證 |
| 文字 | Letter Sealing 加密發送、接收、已讀通知、草稿 | 核心與 GTK 示範流程通過；帳號互傳未驗證 |
| 即時接收 | SSE、斷線重連、refresh token 更新、重複訊息排除 | 本機邏輯與生命週期檢查；真實網路重連與 token 輪替未驗證 |
| 貼圖 | 已擁有貼圖包、靜態縮圖、原生貼圖訊息 | 範圍、到期、擁有權測試及 GTK 選擇器通過；真實貼圖傳送未驗證 |
| 檔案 | 最多 25 MiB，限伺服器明確提供加密流程的對話；附件另存與 HMAC 驗證 | 獨立加密測試向量、竄改拒絕、大小限制、不覆寫既有檔案通過；真實上下載未驗證 |
| 筆記 | 每個帳號、每段對話的本機筆記 | GTK 編輯與私人檔案權限通過；不會同步成 LINE 記事本 |
| 通話 | 顯示簡略來電／通話通知 | 不提供語音或視訊通話 |
| 照片、影音、相簿 | 顯示收到的內容類型；照片可嘗試作為一般檔案傳送 | 無照片專用上傳、影音播放、LINE 相簿或記事本管理 |

LINE 若拒絕特定檔案類型，請先壓縮成 ZIP。檔案下載會拒絕覆寫既有路徑。畫面上的圖片按鈕目前停用，檔案按鈕仍可選擇圖片檔。

聊天記錄保存在記憶體，啟動後向 LINE 取得近期記錄，並非完整歷史備份。此版本沒有新增好友、建立群組、收回訊息、回覆、反應、語音錄音或訊息通知中心整合。

測試不涵蓋實體 GPU、Wayland 或所有桌面環境。實際帳號驗證尚未完成，因此這份專案目前應作為開發預覽版使用。
