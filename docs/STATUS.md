# 功能與驗證狀態

這份清單區分程式已接上的路徑與實際服務互通驗證。離線示範成功不代表 LINE 伺服器已接受該操作。

| 功能 | 目前實作 | 驗證範圍 |
| --- | --- | --- |
| 原生介面 | GTK 4，版面對照 `index.html`：聊天、好友、通話、Keep 筆記、設定、說明、聊天室資訊與各視窗 | Ubuntu 24.04 GTK 4.14（x86_64）與 `index.html` 截圖比對及 36 項 GUI 自動檢查；先前版本曾在 Debian 12 GTK 4.8 與 ARM64 操作，此版尚未重測 |
| 登入 | QR、電子郵件、手機 PIN、取消 | 真實 LINE QR 挑戰產生及取消通過；完整帳號登入未驗證 |
| 登入保存 | 系統鑰匙圈保存 token、憑證與匯出金鑰；不可用時僅存記憶體 | 隔離 Secret Service 寫入、還原與刪除測試 |
| 好友與聊天 | 取得好友、既有私訊與群組、近期訊息、未讀狀態 | 已接上游 API；真實帳號同步未驗證 |
| 文字 | Letter Sealing 加密發送、接收、已讀通知、草稿 | 核心與 GTK 示範流程通過；帳號互傳未驗證 |
| 即時接收 | SSE、斷線重連、refresh token 更新、重複訊息排除 | 本機邏輯與生命週期檢查；真實網路重連與 token 輪替未驗證 |
| 貼圖 | 已擁有貼圖包、靜態縮圖、原生貼圖訊息 | 範圍、到期、擁有權測試及 GTK 選擇器通過；真實貼圖傳送未驗證 |
| 檔案 | 最多 25 MiB，可多選或拖放後確認傳送，限伺服器明確提供加密流程的對話；附件另存與 HMAC 驗證 | 獨立加密測試向量、竄改拒絕、大小限制、不覆寫既有檔案、GTK 傳送佇列通過；真實上下載未驗證 |
| 記事 | 每個帳號、每段對話一則本機記事（標題與內容），顯示於「記事與公告」與「筆記本」 | GTK 編輯與私人檔案權限通過；不會同步成 LINE 記事本 |
| Keep 筆記 | 只存在這台電腦的私人記事聊天，可傳文字與轉傳 | GTK 傳送與保存通過；不會同步到 LINE Keep |
| 置頂、靜音、我的最愛 | 本機偏好，影響列表排序、圖示與通知 | GTK 切換通過；不會改變手機 LINE 的設定 |
| 桌面通知 | 收到訊息時使用系統通知，可在設定關閉，靜音聊天不通知 | 已接 GTK 通知；真實帳號未驗證 |
| 搜尋與轉傳 | 對話內搜尋與標示、複製文字、轉傳文字到其他聊天 | GTK 搜尋計數與示範流程通過 |
| 通話 | 顯示簡略來電／通話通知 | 不提供語音或視訊通話 |
| 照片、影音、相簿 | 顯示收到的內容類型；照片按鈕以一般檔案傳送 | 無照片預覽、照片專用上傳、影音播放、LINE 相簿或記事本管理 |

LINE 若拒絕特定檔案類型，請先壓縮成 ZIP。檔案下載會拒絕覆寫既有路徑。

`index.html` 中尚未支援的操作仍保留相同按鈕位置，按下時會說明此版本不提供，不會假裝完成：語音與視訊通話、建立群組、新增好友、擷取畫面。示範模式的照片拼貼與「共享的片刻」使用與 `index.html` 相同的原創插畫。

聊天記錄保存在記憶體，啟動後向 LINE 取得近期記錄，並非完整歷史備份。此版本沒有新增好友、建立群組、收回訊息、回覆、反應或語音錄音。

測試不涵蓋實體 GPU、Wayland 或所有桌面環境。實際帳號驗證尚未完成，因此這份專案目前應作為開發預覽版使用。
