# 功能與驗證狀態

這份清單區分程式已接上的路徑與實際服務互通驗證。離線示範成功不代表 LINE 伺服器已接受該操作。

| 功能 | 目前實作 | 驗證範圍 |
| --- | --- | --- |
| 原生介面 | GTK 4，版面對照官方 LINE PC 版：登入、聊天、好友、聊天室資訊、貼圖面板、設定；淺色／深色 | Ubuntu 24.04 GTK 4.14（x86_64）實機使用；69 項 GUI 自動檢查（其中 2 項需要桌面 portal 的檔案選擇器） |
| 登入 | QR（自動產生）、電子郵件、手機 PIN、自動登入、恢復上次登入 | 真實帳號 QR 登入與重開後恢復已驗證 |
| 登入保存 | 系統鑰匙圈保存 token、憑證與匯出金鑰；關閉自動登入或鑰匙圈不可用時僅存記憶體 | 真實帳號與隔離 Secret Service 測試 |
| 好友與聊天 | 好友（我的最愛、官方帳號分區）、群組、有訊息的聊天、未讀數 | 與手機上的好友、群組與聊天數量比對一致 |
| 文字 | Letter Sealing 加密收發、回覆、收回、已讀（開啟聊天時向 LINE 取得各成員已讀到哪裡，較早的訊息也會標示）、草稿、複製（可只複製選取的部分）、轉傳；網址自動變成可點擊的連結；官方帳號與超大群組（無 Letter Sealing）改以未加密文字傳送並標示「此聊天未加密」 | 真實帳號收發；未加密傳送的判斷以實際帳號試算（24 個官方帳號、2 個超大群組），尚未實際送出 |
| 即時接收 | SSE、斷線重連、refresh token 更新、重複訊息排除；長時間離線後重新同步清單而不重播 | 真實帳號日常使用；長時間 token 輪替仍在觀察。大量訊息與重新同步以離線測試驗證（3000 則積壓訊息、假核心），尚待真實帳號回報 |
| 貼圖 | 已擁有的貼圖包、最近使用、搜尋 | 範圍、到期、擁有權測試；真實帳號載入 64 組 |
| 表情貼 | 基本表情、已擁有的 LINE 表情貼（可與文字混排） | 真實帳號載入 4 組；帶表情貼訊息的格式依上游實作，送出新版本後仍需更多實際回報 |
| 照片 | 縮圖、照片檢視器（覆蓋在視窗上，左右切換同一聊天的照片，`←`／`→`、`Esc`）、複製圖片、另存、貼上或拖放傳送、螢幕截圖（portal）；照片以私人暫存檔交給介面，不限大小 | 真實帳號收發；大於 2 MiB 的照片以離線測試驗證 |
| 檔案 | 最多 25 MiB，可多選或拖放後確認傳送；附件另存與 HMAC 驗證；檔案訊息依類型顯示圖示與副檔名、過長的檔名省略中段，並顯示大小與有效期限（LINE 有提供時）；加密檔案的檔名從加密內容取得 | 加密測試向量、竄改拒絕、大小限制、不覆寫既有檔案 |
| 記事、Keep 筆記 | 只存在這台電腦 | 私人檔案權限測試；不會同步到手機 |
| 置頂、靜音 | 本機偏好，影響列表排序與通知 | 不會改變手機 LINE 的設定 |
| 桌面通知 | 系統通知，可在設定關閉；本機或手機上靜音的聊天不通知；短時間內大量訊息合併為一則摘要；聊天在這台電腦或手機上讀過後收回通知，結束 LINE 時一併收回 | GNOME 實機；收回邏輯以 GUI 自動檢查驗證 |
| dock 未讀數 | LINE 開著時 dock 圖示顯示未讀數（與「聊天」相同，不含靜音的聊天）；未開啟或未登入時不顯示 | 以 GUI 自動檢查確認送出的數字；Ubuntu Dock 的顯示方式依其原始碼，尚待實機確認 |
| 程式更新 | 開啟 LINE 時檢查 GitHub 上的新版本，由使用者選擇「立即更新」或「暫不更新」；更新會下載安裝包、驗證 SHA256、替換程式並重新開啟，登入與設定保留。設定可關閉啟動時檢查，或手動「檢查更新」。從原始碼執行時只提示以 `git pull` 更新 | 以 GitHub 上的 v1.0.3 發布實際更新：1.0.2 的安裝資料夾取得、驗證並安裝 1.0.3；更新後自動重開以假的發布伺服器在介面上測試；驗證失敗、內容異常、取消與中途失敗還原以自動檢查驗證 |
| 背景執行 | 關閉視窗只隱藏，LINE 繼續接收訊息；dock 圖示右鍵「結束 LINE」、`Ctrl+Q` 或選單「結束 LINE」才會結束 | 以獨立 D-Bus 工作階段測試 `--quit` |
| 通話 | 顯示簡略來電／通話通知 | 不提供語音或視訊通話 |

LINE 若拒絕特定檔案類型，請先壓縮成 ZIP。檔案下載會拒絕覆寫既有路徑。

尚未支援的操作仍保留與官方相同的按鈕位置，按下時會說明此版本不提供：語音與視訊通話、建立群組、新增好友。

聊天記錄向 LINE 取得，並非完整歷史備份：開啟聊天時取得最近的訊息，往上捲動再一頁頁取得更早的。LINE 只提供這種登入最近 14 天的訊息（以真實帳號實測，任何聊天最早只到 14 天前），更早的只在手機上；訊息也不會存在這台電腦，重開後重新取得。目前沒有編輯訊息、反應或語音錄音。

測試不涵蓋所有發行版與桌面環境。遇到問題歡迎在 GitHub 回報。
