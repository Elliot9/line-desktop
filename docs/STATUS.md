# 功能與驗證狀態

這份清單區分程式已接上的路徑與實際服務互通驗證。離線示範成功不代表 LINE 伺服器已接受該操作。

| 功能 | 目前實作 | 驗證範圍 |
| --- | --- | --- |
| 原生介面 | GTK 4，版面對照官方 LINE PC 版：登入、聊天、好友、聊天室資訊、貼圖面板、設定；淺色／深色 | Ubuntu 24.04 GTK 4.14（x86_64）實機使用；47 項 GUI 自動檢查 |
| 登入 | QR（自動產生）、電子郵件、手機 PIN、自動登入、恢復上次登入 | 真實帳號 QR 登入與重開後恢復已驗證 |
| 登入保存 | 系統鑰匙圈保存 token、憑證與匯出金鑰；關閉自動登入或鑰匙圈不可用時僅存記憶體 | 真實帳號與隔離 Secret Service 測試 |
| 好友與聊天 | 好友（我的最愛、官方帳號分區）、群組、有訊息的聊天、未讀數 | 與手機上的好友、群組與聊天數量比對一致 |
| 文字 | Letter Sealing 加密收發、回覆、收回、已讀、草稿、複製、轉傳 | 真實帳號收發 |
| 即時接收 | SSE、斷線重連、refresh token 更新、重複訊息排除 | 真實帳號日常使用；長時間 token 輪替仍在觀察 |
| 貼圖 | 已擁有的貼圖包、最近使用、搜尋 | 範圍、到期、擁有權測試；真實帳號載入 64 組 |
| 表情貼 | 基本表情、已擁有的 LINE 表情貼（可與文字混排） | 真實帳號載入 4 組；帶表情貼訊息的格式依上游實作，送出新版本後仍需更多實際回報 |
| 照片 | 縮圖、圖片檢視器、複製圖片、另存、貼上或拖放傳送、螢幕截圖（portal） | 真實帳號收發 |
| 檔案 | 最多 25 MiB，可多選或拖放後確認傳送；附件另存與 HMAC 驗證 | 加密測試向量、竄改拒絕、大小限制、不覆寫既有檔案 |
| 記事、Keep 筆記 | 只存在這台電腦 | 私人檔案權限測試；不會同步到手機 |
| 置頂、靜音 | 本機偏好，影響列表排序與通知 | 不會改變手機 LINE 的設定 |
| 桌面通知 | 系統通知，可在設定關閉，靜音聊天不通知 | GNOME 實機 |
| 通話 | 顯示簡略來電／通話通知 | 不提供語音或視訊通話 |

LINE 若拒絕特定檔案類型，請先壓縮成 ZIP。檔案下載會拒絕覆寫既有路徑。

尚未支援的操作仍保留與官方相同的按鈕位置，按下時會說明此版本不提供：語音與視訊通話、建立群組、新增好友。

聊天記錄啟動後向 LINE 取得近期訊息，並非完整歷史備份；目前沒有編輯訊息、反應或語音錄音。

測試不涵蓋所有發行版與桌面環境。遇到問題歡迎在 GitHub 回報。
